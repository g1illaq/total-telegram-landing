# Total Telegram — лендинг курса

Статический сайт (HTML/CSS/JS, без сборки) — тот же паттерн деплоя, что у соседних лендингов (Vercel, `cleanUrls`).

- `index.html` — разметка всех 14 экранов + header/footer.
- `styles.css` — дизайн-система (тёмный фон, оранжевый акцент, JetBrains Mono для лейблов/чисел, Inter для текста) и адаптив.
- `config.js` — весь контент (программа, результаты, аудитория, FAQ, тарифы и т.д.) вынесен сюда, чтобы менять данные без правки вёрстки.
- `script.js` — рендер блоков из `config.js`, аккордеоны (программа/FAQ), sticky-хедер, мобильное меню, scroll-reveal анимации.
