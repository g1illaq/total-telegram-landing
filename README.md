# Total Telegram — сайт курса

Продающий лендинг курса **Total Telegram** + линейка из 5 бесплатных лид-магнитов + страница публичной оферты. Статические сайты (HTML/CSS/JS, без сборки), задеплоены на Vercel.

## Живые ссылки

**Лендинг курса** — https://total-telegram-landing.vercel.app

**Лид-магниты** (полноценные лендинги, не PDF — работают одинаково у всех студентов):
- [Разбор Telegram-канала за 15 минут](https://total-telegram-landing.vercel.app/lead-magnets/01-razbor-kanala-15-min) — чек-лист на 30 пунктов, живой подсчёт баллов
- [50 идей контента для Telegram](https://total-telegram-landing.vercel.app/lead-magnets/02-50-idey-kontenta) — матрица 5 типов контента × 10 идей
- [Как выбрать канал для рекламы](https://total-telegram-landing.vercel.app/lead-magnets/03-kak-vybrat-kanal-dlya-reklamy) — 12 пунктов проверки + редактируемая таблица сравнения каналов
- [Telegram Ads: первый запуск](https://total-telegram-landing.vercel.app/lead-magnets/04-telegram-ads-pervyy-zapusk) — от «подходит ли вам Ads» до карты метрик
- [7 способов зарабатывать на канале](https://total-telegram-landing.vercel.app/lead-magnets/05-7-sposobov-zarabatyvat) — карта моделей монетизации

**Юридический документ** — https://total-telegram-landing.vercel.app/oferta (структура публичной оферты, часть полей — TODO, см. ниже)

## Структура репозитория

```
index.html          — лендинг курса (14 экранов)
styles.css           — дизайн-система лендинга (токены, компоненты, адаптив)
script.js             — рендер блоков лендинга из config.js, аккордеоны, sticky-хедер
config.js            — ВЕСЬ контент лендинга (программа, тарифы, FAQ, автор и т.д.)
oferta.html          — страница публичной оферты (самодостаточный файл)
lead-magnets/
  01-razbor-kanala-15-min.html      — самодостаточные HTML-лендинги,
  02-50-idey-kontenta.html          — каждый со своими встроенными
  03-kak-vybrat-kanal-dlya-reklamy.html   CSS/JS, без внешних зависимостей
  04-telegram-ads-pervyy-zapusk.html      кроме шрифтов Google Fonts
  05-7-sposobov-zarabatyvat.html
assets/
  author-photo.jpg    — временное фото автора (плейсхолдер, см. TODO)
vercel.json           — конфиг деплоя (cleanUrls: true — /oferta вместо /oferta.html)
```

Лендинг курса — единственная часть с вынесенным контентом (`config.js` + `script.js` рендерят разметку). Лид-магниты и оферта — цельные файлы «как есть», редактируются напрямую в HTML.

## Дизайн-система

Бренд взят с реальных PDF-конспектов курса (не придуман): почти чёрный фон `#060607`, насыщенный оранжево-красный акцент `#ff4d1f`, шрифты **Unbounded** (заголовки/лейблы) + **Golos Text** (текст), тонкая квадратная сетка на фоне, фирменная рамка с оранжевыми уголками (класс `.brand-frame`) — повторяет визуальный штамп «TOTAL» из материалов курса.
